# 空道十六进制计算器

空道十六进制计算器是一个使用 Python 和 PyQt5 开发的桌面版十六进制计算工具。它主要面向逆向分析、底层调试、二进制分析、协议解析等场景，帮助使用者快速完成十六进制数值运算和常见数据格式转换。

项目提供了常用的十六进制运算能力，包括加、减、乘、除、取模、异或、与、或、左右移、循环左移、循环右移、按位取反等，结果会按 64 位掩码输出。同时，它还支持有符号整数、无符号整数和十六进制之间的转换，支持 LEB128、ULEB128 与十六进制之间的转换，并提供 float、double 与十六进制表示的互转能力。界面基于 Tab 组织，可以新建多个计算页签，**双击页签可以重命名标题并添加备注**。

## 功能特性

- 十六进制基础运算：`+`、`-`、`*`、`/`、`%`
- 位运算：`^`、`&`、`|`、`~`
- 移位与循环移位：`<<`、`>>`、`<<<`、`>>>`
- **位宽切换：8/16/32/64 位单选，每个 tab 独立保存。切换时自动按新位宽对所有已填字段重算（取反、移位、循环移位、加减乘除等）**
- 有符号整数、无符号整数、十六进制互转
- LEB128、ULEB128 与十六进制互转
- float、double 与十六进制互转
- **Unix 时间戳 ⇄ 日期互转：支持秒/毫秒单位切换（毫秒形式 `YYYY-MM-DD HH:MM:SS.fff`），按本地时区显示**
- 多标签页计算，可为不同任务建立独立计算页
- **双击页签可自定义标题并添加备注**
- 历史记录：自动保存最近 100 次成功计算（持久化到 `~/.hexcalc/history.json`），双击列表项可一键回填到当前活动 tab
- 支持通过 PyInstaller 打包为 macOS 桌面应用

## 项目结构

```text
.
├── main.py              # 应用入口和主要业务逻辑
├── buildapp.sh          # macOS 应用打包脚本
├── ui/
│   ├── mainui.ui        # Qt Designer 主界面文件
│   ├── mainui.py        # 由 mainui.ui 生成的 PyQt5 界面代码
│   ├── dialog.ui        # 标签页编辑对话框 UI
│   ├── dialog.py        # 由 dialog.ui 生成的 PyQt5 界面代码
│   └── Calculator.icns  # 应用图标
└── utils/
    ├── kdutils.py       # 十六进制、字节、LEB128 等工具函数
    ├── kdsignals.py     # PyQt 信号定义
    └── history.py       # 历史记录管理（持久化、去重、容量上限）
```

## 运行环境

项目依赖 Python 3 和 PyQt5。

```bash
pip install PyQt5
python3 main.py
```

## 打包应用

项目提供了 `buildapp.sh`，可使用 PyInstaller 打包为 macOS 可执行程序。

```bash
chmod +x buildapp.sh
./buildapp.sh
```

打包完成后，可执行文件会生成在 `dist/` 目录下，应用名称为 `calc`。

## 适用场景

这个工具适合在以下工作中作为轻量级辅助计算器使用：

- 逆向工程中的地址、偏移、掩码计算
- 二进制协议字段分析
- Android、iOS 或嵌入式底层调试
- LEB128、ULEB128 编码值快速换算
- 浮点数和二进制表示之间的快速确认
